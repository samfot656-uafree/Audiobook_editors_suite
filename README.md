# Audiobook_editors_suite
Комплекс для підготовки тексту книги до озвувування певною TTS.
Для кожної книги створюється структура папок проекту.
Додаємо наголоси автоматично, перевіряємо на слух, виправляємо вручну.
Додаємо теги голосів мовців з вказівкою швидкості вимови.
Додаємо теги файлів звукових ефектів. Складаємо список з описом ефекту та шляхом до файлу. Копіюємо файли до папки ефектів в проекті книги.
Озвучуємо текст з додаванням мелодій початку та кінця глави, пауз і звукових ефектів. Фрагменти кожної глави об'єднуємо в звукові файли глав.
Створено і працює на телефоні Андроїд.
Підготовка тексту виконується на телефоні.
Фінальне озвучування має виконуватися на комп'ютері з TTS.
